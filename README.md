# 基于 Node.js + MongoDB 的在线问卷系统

## 项目简介
本项目是一个支持动态跳转、复杂校验、题库复用与版本控制的在线问卷系统（类似问卷星）。系统不仅支持用户注册、创建问卷、分享填写，还经历了架构演进，实现了将题目从问卷中解耦，支持题目共享、历史版本追溯，并基于 MongoDB 聚合管道实现了跨问卷的统计分析。

## 核心功能特性
- **用户模块**：注册、登录、JWT 鉴权。
- **问卷管理**：创建问卷、发布、关闭，支持分享短链接。
- **动态跳转**：基于数据库配置的规则引擎，支持根据用户答案动态跳转题目，内置防死循环机制。
- **题库与版本控制（第二阶段新增）**：
  - 题目独立于问卷，存入题库。
  - 修改题目不会覆盖旧数据，而是生成新的版本快照（v1 -> v2 -> v3）。
  - 问卷通过 `question_refs` 引用题库，保障已发布问卷的数据一致性。
- **跨问卷统计**：利用 MongoDB 聚合管道（`$unwind`, `$group`），支持统计某一题目在所有引用它的问卷中的总体回答分布。
